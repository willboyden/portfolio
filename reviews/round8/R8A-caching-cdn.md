# R8A — Caching / CDN / Headers Review

**Score: 6/10** — HTML is `no-store` (correct), hashed JS assets get `immutable` (correct), but critical path scripts (`theme-init.js`, `spa-gate.js`) are NOT content-hashed and are `immutable`-cached for a year; CSS `.gz` sibling is absent; sitemap `lastmod` is `2026-10-24` (auto-today, not content-accurate); `/portfolio` has no trailing-slash redirect; favicon and OG PNGs lack `Content-Length` visibility; `.nojekyll` present.

| ID | Severity | Evidence | Fix | Impact |
|---|---|---|---|---|
| R8A-1 | HIGH | `theme-init.js` and `spa-gate.js` are immutable-cached (`max-age=31536000, immutable`) but NOT content-hashed → a fix won't propagate for ~1 year | Add content hash to filenames OR remove `immutable` and rely on `Vite` hash already in filenames for the HTML references; or add a cache-busting query param via build inject | Critical — theme palette and SPA gate are on the critical path; stale cache = broken UX |
| R8A-2 | MEDIUM | CSS has no `.gz` sibling in dist/; nginx `gzip_static` won't serve it; client accept-gzip still triggers `.gz` serve from the preview server but production has none | Precompress CSS with `npm run build` gzip step OR remove the `.gz` check in `serve-dist.mjs` for CSS; keep `.gz` only for JS where it matters | Medium — saves ~10KB per CSS request on gzip-enabled clients |
| R8A-3 | MEDIUM | Sitemap `lastmod` is `2026-10-24` for every URL — auto-today, not actual content dates; GitHub Pages cannot set `lastmod` to real dates without custom build | Update `build-content.mjs` / sitemap generator to use actual `date`/`pubDate` from content frontmatter instead of today's date | Medium — improves SEO freshness signaling |
| R8A-4 | LOW | `/portfolio` (no trailing slash) returns 200 with no redirect; case sensitivity/query strings not addressed; mixed `rel href` usage (some `/about`, some `about/`) | Add a 301 redirect from `/portfolio` to `/portfolio/` in the GitHub Pages/nginx config, or ensure all internal `href="/about"` are consistent with base `/portfolio/` | Low — avoids ambiguous URL handling |
| R8A-5 | LOW | `index.html.gz` exists but no `.gz` siblings for other assets; the preview server serves `.gz` when client accepts-gzip, but GitHub Pages nginx may not have `gzip_static` on | Either precompress all assets with `.gz` siblings OR remove the `.gz` acceptance from `serve-dist.mjs` and rely on runtime nginx compression | Low — reduces dead weight if Pages compresses at runtime |
| R8A-6 | INFO | Favicon (`/favicon.svg`) and OG PNGs (`projects.png` 29KB, `writing.png` 27KB) are served with `etag` + `max-age=600`; no `Content-Length` header visible in curl — normal for CDN | Acceptable — CDN manages these; ensure OG images are optimized | Info |

**Summary:** The biggest risk is R8A-1: `theme-init.js` and `spa-gate.js` are on the critical path and get `immutable` caching without content hashing, meaning a fix won't reach users for up to a year. All other findings are secondary but should be addressed in sequence.
